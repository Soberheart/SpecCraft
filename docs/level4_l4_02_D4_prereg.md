## 1. 共同口径

- **官方查询网格**：`check_level3_dyn.py`/`net/pipeline/pipeline.py` 的验证网格（x ±60 mm、y ±104 mm、z −1…23 mm，2 mm 间距，61×105×13 = 83 265 点）。
- **真值**：执行日志经官方 `sim/process.py`（`--config-name common num_frames=63`，与 L3 处理同命令）生成网格，`get_label` 取占据与组件标签；工具网格内部、z<0 的格子按仓库 `Evaluater` 规则一律视为空。
- **VIoU/CIoU/AccC/AccG**：仓库 `Evaluater.accuracy`（与 L3 诊断同一函数、同一掩码）。
- **预测**：
  - 主：B-dyn 已冻结的 latent（`latents.npz`，hash 校验），v3 工具输入为主，legacy 为次；在官方网格上 decode。
  - 次：用执行自身的渲染观测（`Renderer`，种子 = 0 + 帧号）和执行工具点云做单步、AE 重建和“记录工具 rollout”。
- **候选**：35 个已执行候选（冻结 16 + seed1 15 + d2_edge 4；candidate_024 不执行）。敏感性运行不进入 D4。
- **时间**：0→5→…→60 共 12 个预测区间（0.16 s）；frame60 为主端点。

## 2. P1–P4

### 2.1 原判定（L4-01 §3，按冻结原文执行并报告）

### 2.2 参照不匹配（需总览在提交前决定）

原 P1/P2 的 78.95% = L3 **12 区间平均** 81.95% − 3 pp，却拿来卡 **frame60 单点**。按这个原文，L3 自己的名义执行（frame60 = 57.34%）也判不通过，所以原 P1/P2 区分不了“管线/分布问题”和“这个模型长时 rollout 本来就是这个水平”。这是 L4-01 Phase A 写判定时的错误（执行 agent 的责任），在任何 L4 官方网格指标算出之前发现。

### 2.3 同类比较的修正判定（建议作为 D4 主判定；需总览批准）

| 判据 | 通过条件（全部满足） | 依据 |
|---|---|---|
| P1′ candidate_000、v3 rollout | 12 区间平均 ≥ 78.95% **且** frame60 ≥ 54.34% | L3 平均 81.95 − 3；L3 frame60 57.34 − 3 |
| P2′ 有效执行候选（≥20，否则不确定） | 12 区间平均的中位数 ≥ 78.95% **且** frame60 中位数 ≥ 54.34% | 同上 |
| P3′ 单步 | 每候选 12 区间单步平均，其中位数 ≥ 88.91% | L3 单步平均 91.91 − 3 |

两套判定都计算并报告；作业提交前由总览指定哪一套作为 D4 结论（未指定时，报告两套且不下 D4 结论）。

### 2.4 P4（两套共用）

- 量：frame60 v3 rollout 在官方网格（已屏蔽 z<0 与工具）上的 u 跨度、v 跨度（体素极值 + 2 mm 单元）和捏合颈宽（捏合坐标系，4 mm 切片，占据格中心），与同口径真值的绝对误差。
- L3 参照（同代码，§0）：u 16.0 mm，v 10.0 mm，颈宽 1.0 mm。
- 判定：每项 L4 误差中位数 / L3 参照 ∈ [0.1, 10] → 通过；> 10 → 不通过；< 0.1 记为“优于参照”（不算失败）；无法计算 → 不确定。三项全通过才算 P4 通过。

### 2.5 D4 结论

D4 = 通过：P1–P3 全通过，且 P4 通过或不确定；不通过：P1–P3 任一不通过；否则不确定。

## 3. 管线正对照（B2.2）

对象：L3 scene0000 名义执行（旧初态、旧语义）。
- PC-a：L3 已存观测 + L3 处理数据中的记录工具点云，经 B-dyn 同一套函数（`reconstruct` → 逐区间 `predict(decode=False)` → 官方网格 `decode`）计算 rollout 与单步 VIoU，并与 L3 记录逐区间比较；latent 与 L3 已存 `z_predicted` 比较。
- PC-b（只报告）：池中的 L4 输入（v3 reset 初态观测 + legacy 名义工具）在 L3 真值上的 rollout VIoU。

| 结果 | 条件 |
|---|---|
| 正常 | rollout 平均与单步平均都在 L3 记录 ±1 pp 内，且 latent 最大绝对差 ≤ 1e-3 |
| 异常 | rollout 平均或单步平均比 L3 记录低 3 pp 以上 |
| 不确定 | 其余 |

## 4. 桌面与 z 坐标（B2.3）

| 编号 | 量 | 判定 |
|---|---|---|
| Z1 | v3 rollout（L4 1 mm 冻结网格，k=1…12，35 候选合计）中 z<0 的占据格，落在训练查询必然覆盖范围之外（z < −7.5 mm）的比例。训练 box 查询下限为 −0.05×scale，scale∈[0.75,1.25]，即 −7.5…−12.5 mm | ≥ 80% → 查询域外外推；≤ 20% → 域内的桌面以下预测；其余 → 混合 |

## 5. 动作敏感性（B2.4）

- 属性（官方网格同口径）：
  - 颈宽@60（T1′）、v 跨度最大增量 dv_max（T2′）为主；
  - u/v 跨度@60 为次。
- 量：35 候选上预测方差 / 执行方差 R，以及 Spearman ρ（置换 10 000 次，单侧 p）。

| 结果 | 条件 |
|---|---|
| 随动作变化且排序一致 | R ∈ [0.25, 4]，ρ ≥ 0.5，p < 0.05 |
| 对动作不敏感 | R < 0.25 |
| 有变化但排序不对 | R ≥ 0.25 且 ρ < 0.2 |
| 不确定 | 其余 |
