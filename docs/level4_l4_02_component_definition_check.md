## 3. 为什么不一致

1. **两种口径测的是不同的东西。**
   - 模拟器标签来自 `sim/generate/topology.py` 的 SceneGraph：它从初态的平面图出发，在手指闭合时用“检查动作”把手指两侧的区域拉开，按距离阈值（`check.min_dist` = 2 个 MPM 网格 = 0.03125 单位 = 6.25 mm）记录合并或分裂。它回答的是“如果拉开，两侧会不会分开”。
   - L4 粒子连通回答的是“当前这一刻粒子是否连成一体”。
2. **被标为分裂之后，两块仍然接触，而且越压越紧。** 跨块最小距离 0.3–0.5 mm，远小于 r0 = 2.64 mm。相距 ≤ r0 的粒子对从约 330 对增加到约 1000 对。弹塑性 MPM 没有断裂模型，手指没有把材料完全推开时，粒子不会真正分离。
3. **训练与评测用的是模拟器标签。**
   - DoughNet 的组件标签（`obj_vert_labels`、`genus`，AccC/AccG 指标）都来自它；
   - 处理后的网格按标签分块，`sim/process.py` 会断言两者一致。
   - 所以 L3 记录的“1 → 2 个组件”是训练口径下的真实标签，并不是数据错误。

## 4. 对 D2/T3/T4 的含义（供总览决策）

- L4-01 的结论“38 次执行无一断开”只在**粒子连通口径**下成立。按**模拟器/训练口径**，名义动作 c000 与 c001 都在 frame57 被“捏成两块”，而且接近均分。
- 当前池中按模拟器口径有多少候选分裂、多少不分裂（即是否存在“断/不断”边界），由服务器上的 A1 输出逐 run 给出。如果两类都有，T3/T4 在当前初态上就可以研究，B3（可断初态）可能不需要新仿真。
- 论文中的“断”需要选定一个口径：
  - **模拟器标签**：与模型的拓扑头、训练数据一致，但它是“拉开会分离”的语义判断；
  - **粒子几何**：更接近真机上能观测的“物理分开”，但在当前仿真器里几乎不会出现。
  - 也可以两种都报告，用标签作任务定义、几何作保守的物理检查。
  - 这是研究定义问题，**需要总览拍板**。
