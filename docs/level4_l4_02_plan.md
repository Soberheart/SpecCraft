## 2. B1 噪声底判定（看到 B1 数据前写定）

- **重复集**：
  - candidate_000：原执行、S0_repeat_nominal、N_candidate_000_r1、N_candidate_000_r2（4 次，6 对）；
  - candidate_012：原执行、N_candidate_012_r1、N_candidate_012_r2（3 次，3 对）。
- **重复最大差**：任意两次之间逐帧（0–62）原始粒子 u/v 跨度、捏合颈宽的最大绝对差；另记任意帧、任意连通倍数下显著组件数是否不同。
- **偏移变化**：
  - S1_x_0p02、S1_y_0p02 相对 candidate_000；
  - S4_candidate_012_x_0p02 相对 candidate_012。
  - 同一套逐帧比较。
- **比值**：偏移颈宽变化 / 该候选重复颈宽最大差。偏移运行出现组件数变化、而重复运行之间没有，视为“超过”。

| 档 | 条件（按顺序判断） | 结论（审核二.2） |
|---|---|---|
| 三 | 粗颈名义 candidate_000 上任一偏移的比值 > 2（“明显大于”的操作化），或组件数变化超过重复 | 0.02 mm 对颈宽确实失效；颈宽任务接口门槛另行收紧并先排查放大机制 |
| 一 | 两个候选上所有偏移的比值都 ≤ 1，且无组件变化超过重复 | 变化来自仿真自身不确定性；0.02 mm 门槛对颈宽同样有效；颈宽 ε ≥ 噪声底 × 3 |
| 二 | 细颈 candidate_012 的比值 > 1（或组件变化超过重复），candidate_000 的比值 ≤ 2 | 临界敏感性；不收紧门槛，记入 L5，由校准裕量处理 |
| 一（边缘） | 只有 candidate_000 的比值在 (1, 2] 内 | 按第一档处理，并在报告中标明边缘 |

“明显大于 = 超过重复最大差的 2 倍”是执行 agent 对审核措辞的操作化，**请总览确认或修改**。

## 3. 本次已发现、需总览先看的事实（详见 L4-02 中期回报）

1. L4 初态不是方块，是 DoughNet 默认甜甜圈（genus 1），与 L3 scene0000 是同一场景、同一名义动作。
2. L4-01 写定的 D4 P1/P2 用 L3 的 12 区间平均（81.95%）去卡 frame60 单点（L3 自身 57.34%），需要修正（见 D4_prereg §2.2–2.3）。
3. 模拟器（训练标签）在名义动作下把环标为 frame57 一分为二（两块各 genus 1，质量比 0.92–0.99）；L4 粒子连通口径始终 1 块，两块之间仍有数百对粒子相距不到 r0。
4. 官方 `Evaluater` 本来就忽略 z<0 与工具内部的格子；L4-01 的量测没有屏蔽，这是“触底 → unknown”的直接原因之一。
